# Clínica Vida Plena

Site simples de uma clínica, feito para fins didáticos.

## Sobre o projeto

Este é o primeiro projeto do curso de Programador Web. Eu o uso com os alunos para explicar, na prática, como funciona uma página feita só com HTML e CSS.

## Objetivo

Mostrar como uma página real é montada passo a passo: a estrutura com HTML, o visual com CSS e um formulário de contato funcionando com a API do Formspree, sem precisar de servidor próprio.

## O que a página tem

- Cabeçalho com o nome da clínica
- Bloco "Sobre nós" com uma foto de fundo
- Lista de serviços
- Formulário de contato

## Tecnologias

- HTML
- CSS
- Formspree (API para receber as mensagens do formulário)

## Publicação

A página está publicada pelo GitHub Pages.

## Aviso

A Clínica Vida Plena é fictícia. O conteúdo existe apenas para as aulas.
